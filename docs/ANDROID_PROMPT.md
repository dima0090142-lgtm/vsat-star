# Промт: VSAT STAR для Android

Этот промт можно целиком отдать ИИ-ассистенту (Claude Code, Cursor и т. п.), чтобы он разработал Android-версию программы. Всё, что нужно знать о панели судна и поведении Windows-версии, в нём уже есть.

---

## Задача

Разработай нативное Android-приложение **VSAT STAR**. Это аналог Windows-программы VSAT STAR S/W v4.3 (Python + PySide6, исходники: https://github.com/dima0090142-lgtm/vsat-star).

Приложение работает на судне. Телефон подключён к судовому Wi-Fi, и через локальную веб-панель `http://192.168.50.2` члены экипажа переключают спутниковый интернет между терминалами **Starlink** и **VSAT**, завершают сессию (logout) и смотрят остаток трафика. Приложение должно делать это в одно касание, без ручного входа в веб-панель.

Главное ограничение: **спутниковый трафик дорогой**. Нельзя делать лишних сетевых запросов, фоновых опросов чаще, чем нужно, загрузки шрифтов, картинок или аналитики из интернета. Никакой телеметрии и сторонних SDK.

## Технологии

- Kotlin, Jetpack Compose (Material 3), minSdk 26, targetSdk — последний стабильный.
- Архитектура MVVM: `ViewModel` + `StateFlow`, корутины. Слои `data` (сеть, хранилище), `domain` (парсер, логика лимита), `ui`.
- Сеть: OkHttp с `CookieJar` в памяти. Сессия (cookies) живёт, пока жив процесс, как `requests.Session` в оригинале.
- Хранилище: DataStore для настроек. Пароль шифруется ключом из Android Keystore (AES/GCM). Никаких облачных бэкапов: `android:allowBackup="false"` или исключи файлы из правил бэкапа.
- Фон: WorkManager и/или foreground service (см. ниже), уведомления через `NotificationCompat`.
- Иконки только векторные (`ImageVector` или Material Icons), без растровых ресурсов.
- Сборка: Gradle Kotlin DSL, version catalog. Подписанный release APK через `./gradlew assembleRelease`.

## API локальной панели (повторить один в один)

Базовый адрес `BASE_URL = http://192.168.50.2`. Это обычный HTTP, поэтому нужен `network_security_config.xml`, который разрешает cleartext **только** для `192.168.50.2`.

Общие заголовки для всех запросов:
```
User-Agent: Mozilla/5.0 (Windows NT 10.0; Win64; x64) AppleWebKit/537.36 (KHTML, like Gecko) Chrome/120.0.0.0 Safari/537.36
Accept-Language: ru,en;q=0.9,de;q=0.8
```

### 1. Логин
1. `GET {BASE_URL}/index.php/login` (тайм-аут 10 с) — нужен только для того, чтобы получить свежие cookies сессии.
2. `POST {BASE_URL}/index.php/login` (тайм-аут 10 с)
   - Заголовки: `Content-Type: application/x-www-form-urlencoded`, `Origin: {BASE_URL}`, `Referer: {BASE_URL}/index.php/login`
   - Тело: `username=<логин>&password=<пароль>` (url-encoded)
   - Ошибка, если код ответа не 200: «Ошибка авторизации, код N — проверь логин/пароль». Редиректы выполняются автоматически.

### 2. Переключение терминала (перед ним всегда логин на той же сессии)
`POST {BASE_URL}/index.php/crew/start_internet` (тайм-аут 15 с)
- Заголовки: `Accept: application/json, text/javascript, */*; q=0.01`, `Content-Type: application/x-www-form-urlencoded; charset=UTF-8`, `Origin: {BASE_URL}`, `Referer: {BASE_URL}/index.php`, `X-Requested-With: XMLHttpRequest`
- Тело — **строка JSON**, хотя Content-Type указан urlencoded (так делает оригинальный сайт, повторить буквально): `{"terminal":"Starlink"}` или `{"terminal":"VSAT"}`. Регистр важен.
- Ошибка, если код ответа не 200.

### 3. Отключение / logout (перед ним тоже логин)
`GET {BASE_URL}/index.php/chilli_logout` с заголовком `Referer: {BASE_URL}/index.php` (тайм-аут 10 с). Ошибка, если код ответа не 200.

### 4. Трафик — **без** повторного логина
`GET {BASE_URL}/index.php/card-usage` (тайм-аут 10 с) на уже существующей сессии. Повторный логин может сбросить активное подключение, поэтому его здесь нет. В браузере эта страница сама обновляется каждые 10 секунд и тратит трафик. Приложение запрашивает её один раз за вызов.

### Обработка ошибок (понятные сообщения на русском)
- Тайм-аут → «Панель не отвечает (тайм-аут)». Тайм-аут проверяй раньше общей ошибки соединения.
- Нет соединения → «Нет связи с панелью http://192.168.50.2»
- Остальное → текст исключения.

### Важная особенность Android: маршрут через Wi-Fi
У судового Wi-Fi часто нет «проверенного» интернета, и Android может отправить запросы через мобильную сеть. Все запросы к панели отправляй через сеть Wi-Fi: найди её через `ConnectivityManager` (`NetworkCapabilities.TRANSPORT_WIFI`) и используй `network.socketFactory` в OkHttp, либо `bindProcessToNetwork`. Если Wi-Fi не подключён, сразу покажи понятную ошибку «Подключитесь к судовому Wi-Fi», не дожидаясь тайм-аута.

## Разбор страницы трафика (перенести алгоритм точно, покрыть unit-тестами)

Результат — 4 поля: `downloaded`, `uploaded`, `remaining_data`, `remaining_time`. Если значение не найдено, поле равно `"?"`. Набор полей зависит от терминала (на VSAT «остатка данных» может не быть), поэтому значения раскладываются не по позиции, а по подписи и формату.

1. Найди все `<span>` с классом, содержащим `usageData`. Регулярка (без учёта регистра):
   `<span[^>]*class="[^"]*usageData[^"]*"[^>]*>\s*([^<]*?)\s*</span>`
2. Для каждого совпадения подпись — это HTML между концом предыдущего совпадения и началом текущего: убрать теги, раскодировать HTML-сущности, схлопнуть пробелы, взять последние 60 символов. Значение — раскодированный и обрезанный текст спана. Пустые значения пропускаются.
3. Тип значения:
   - **time**, если совпадает с `\d+:\d{2}|\d+\s*(?:d|h|min|mins|minutes?|hours?|days?|sec|seconds?|дн\w*|ч|час\w*|мин\w*|сек\w*)\b`
   - иначе **data**, если совпадает с `\d\s*(?:[kmgt]i?b|bytes?|[кмгт]б|байт\w*)\b`
   - иначе **other** (без учёта регистра).
4. Ключ по подписи (в нижнем регистре, первое совпадение по порядку — **порядок важен**):
   - `remaining_time`: «time», «врем», «minute», «минут»
   - `downloaded`: «download», «загруж», «скачан», «входящ», «received»
   - `uploaded`: «upload», «отправ», «выгруж», «исходящ», «sent»
   - `remaining_data`: «remaining», «left», «остат», «quota», «balance», «data», «трафик»
5. Формат важнее подписи: если ключ `remaining_time`, а тип data, или ключ другой, а тип time, ключ сбрасывается. Если ключ есть и ещё не занят, значение записывается в него, иначе уходит в «остатки».
6. Остатки по порядку занимают первый свободный слот: time → `remaining_time`; data → `downloaded`, `uploaded`, `remaining_data`; other → любой из четырёх в том же порядке.

### Перевод остатка времени в минуты
`"03:07:23"` → 187.4, `"1 day 02:00:00"` → 1560, `"2 h 15 min"` → 135, `"?"` или пусто → null.
- Дни: `(\d+)\s*(?:d|days?|дн\w*)\b` × 1440
- Если есть `(\d+):(\d{2})(?::(\d{2}))?`, это часы:минуты[:секунды]
- Иначе отдельно часы `(\d+)\s*(?:h|hours?|ч|час\w*)\b` и минуты `(\d+)\s*(?:m|min|mins|minutes?|мин\w*)\b`
- Если ничего не найдено → null.

Напиши JUnit-тесты на парсер: HTML Starlink со всеми четырьмя полями, HTML VSAT без остатка данных (время не должно попасть в `remaining_data`), русские и английские подписи, подписи без подсказок (раскладка только по формату), и все примеры для перевода в минуты.

## Поведение приложения

- **Переключение**: кнопки Starlink / VSAT выполняют логин, затем переключение. После успеха кнопка терминала подсвечивается как активная, статус показывает «Активен: Starlink» и «Подключено в ЧЧ:ММ», плитки трафика сбрасываются в «—». Флаг напоминания о лимите сбрасывается, таймер автообновления запускается заново, а через 3 секунды трафик запрашивается один раз, чтобы сразу узнать остаток времени.
- **Отключить**: логин, затем logout. Активный терминал снимается, статус жёлтый: «Отключено», «Сессия завершена в ЧЧ:ММ».
- **Обновить трафик** (кнопка в шапке и pull-to-refresh): один запрос card-usage. Если все поля равны «?», в подписи показывается «нет данных», а в статусе «Нет данных о трафике — возможно, нужно сначала подключиться».
- **Один запрос за раз**: пока запрос идёт, кнопки неактивны, иконка обновления крутится, статус синий и пульсирует («Переключаю на Starlink…», «Отключаю…», «Запрашиваю трафик…» и подпись «Ожидаю ответ панели»). Новые действия в это время игнорируются.
- **Автообновление трафика каждые 10 минут**, пока приложение открыто или работает активная сессия. Фоновое обновление тихое: при ошибке меняется только подпись «ошибка в ЧЧ:ММ», без смены статуса и без уведомлений. У периодического WorkManager минимум 15 минут, поэтому для фона используй foreground service с постоянным уведомлением (тип `dataSync`, только пока терминал активен) или `setExactAndAllowWhileIdle` и честно опиши выбор в README. После «Отключить» фоновое обновление останавливается.
- **Напоминание о лимите**: если остаток времени ≤ 30 минут, плитка «Остаток времени» подсвечивается красным, в статусе появляется «До конца дневного лимита осталось N мин», и приходит уведомление высокой важности «VSAT STAR: заканчивается лимит». Напоминание показывается **один раз** за сессию. Флаг сбрасывается, когда остаток снова становится больше 30 минут или после нового переключения.
- **Уведомления о результате**, если действие запущено не из открытого приложения (виджет, плитка, уведомление): «Активен: VSAT», «Отключено» или ошибка.
- **Смена логина/пароля** создаёт новую сессию (очищает cookies) и снимает активный терминал. Старые cookies с новым пользователем дают ошибку 500.
- **Журнал действий** (необязательный, включается в настройках): строки `[ЧЧ:ММ:СС] текст` в цветах info, ok и error, кнопка очистки. Сюда же пишутся коды ответов сервера и первые 160 символов ответа. В журнале никогда не выводятся логин и пароль.
- Состояние (активный терминал, последние цифры трафика, время обновления) сохраняется при повороте экрана и пересоздании процесса.

## Замена трея и горячих клавиш на Android-аналоги
- **Плитка быстрых настроек** (TileService): показывает активный терминал, по нажатию открывает диалог Starlink / VSAT / Отключить.
- **Виджет на рабочий стол** (Glance): три кнопки и остаток времени.
- **Ярлыки приложения** (App Shortcuts, долгое нажатие на иконку): Starlink, VSAT, Отключить.
- Запрос разрешения `POST_NOTIFICATIONS` на Android 13+ с объяснением, зачем оно нужно.

## Дизайн (как на `docs/screenshot.png`)
Тёмный «стеклянный» стиль (glassmorphism): фон — градиент из глубокого синего в фиолетовый с размытыми цветными пятнами (голубое `#38BDF8` вверху справа, розовое `#EC4899` внизу слева); карточки полупрозрачные белые (~8–12 % непрозрачности) с тонкой светлой обводкой и скруглением 16–20 dp.

Экран сверху вниз:
1. **Шапка**: иконка приложения, «VSAT STAR» и мелкая версия, подзаголовок «Переключатель терминалов», справа кнопки «обновить» и «настройки».
2. **Карточка статуса**: цветная точка (пульсирует во время запроса), заголовок, подробность, время справа. Цвета: ok `#4ADE80`, warn `#FACC15`, error `#F87171`, busy `#60A5FA`, neutral `#CBD5E1`. Начальное состояние: «Готово», «Выберите терминал для подключения».
3. **Раздел «ТЕРМИНАЛ»**: две большие кнопки — Starlink (иконка спутника, акцент `#38BDF8`) и VSAT (иконка тарелки, акцент `#C084FC`). Активная заливается своим акцентом. Ниже на всю ширину кнопка «Отключить» в красноватом стиле `#F87171` с иконкой питания.
4. **Раздел «ТРАФИК»** с подписью справа («авто каждые 10 мин», «обновлено в ЧЧ:ММ», «нет данных», «ошибка запроса»): сетка 2×2 плиток — «Загружено» (стрелка вниз), «Отправлено» (стрелка вверх), «Остаток данных» (база данных), «Остаток времени» (часы, значение жёлтым, красная подсветка при ≤ 30 мин). Нет значения — «—».
5. Подсказка: «Трафик обновляется каждые 10 минут. За 30 минут до конца дневного лимита придёт напоминание.»
6. Журнал (если включён).

Поддержи edge-to-edge, крупные зоны нажатия (≥ 48 dp), TalkBack (contentDescription), системный размер шрифта. Весь интерфейс на русском, строки вынеси в `strings.xml` с английским переводом.

Версия берётся из `tag_name` без префикса v/V, ссылка — из первого ассета `.apk` (иначе `html_url`). Сравнение версий по числам с дополнением нулями (`4.3` < `4.3.1` < `4.10`). Результат: «У вас последняя версия» зелёным, «Доступна версия X — скачать» жёлтым со ссылкой, ошибка красным. Этот запрос идёт через обычный интернет, а не через привязку к Wi-Fi панели.

## Безопасность и приватность
- Логин и пароль нигде не зашиты в коде (репозиторий открытый), они вводятся только в настройках.
- Cleartext разрешён только для `192.168.50.2`.
- Никакой аналитики, крэш-репортеров и рекламы. Разрешение `INTERNET` нужно; `ACCESS_NETWORK_STATE` нужно для выбора Wi-Fi; разрешения на геолокацию запрашивать нельзя.
