# VSAT STAR для Android

Простое приложение для телефона: переключает спутниковый интернет на судне между
**Starlink** и **VSAT** и отключает его одной кнопкой. Делает то же, что Windows-версия
(`terminal_switch.py`), через ту же панель `http://192.168.50.2`.

## Возможности

- Список терминалов **Starlink** / **VSAT** с галочкой у активного и пункт **Отключить интернет**
- Три темы оформления в настройках: **Обычная**, **Telegram**, **Терминал (MS-DOS / Linux)**.
  Скриншоты всех тем выкладываются в [релиз android-latest](https://github.com/dima0090142-lgtm/vsat-star/releases/tag/android-latest)
- Только вертикальная ориентация экрана
- Трафик: остаток времени и данных, загружено / отправлено. Обновляется сам раз в 10 минут или жестом "потянуть вниз", как в браузере
- **Значок в шторке**: в строке состояния видно, какое сейчас подключение
  (спутник - Starlink, тарелка - VSAT, кнопка питания - отключено), а в уведомлении -
  остаток времени и кнопки быстрого переключения
- Напоминание за 30 минут до конца дневного лимита
- **Экспериментально** (включается в настройках): автоотключение интернета, если через
  Wi-Fi телефона час почти нет трафика (меньше 2 МБ). Учитывается только трафик этого телефона.
- Запросы к панели всегда идут через Wi-Fi, даже если Android считает, что у Wi-Fi нет интернета
- Логин и пароль хранятся только на телефоне

## Установка

1. Откройте на телефоне ссылку
   <https://github.com/dima0090142-lgtm/vsat-star/releases/download/android-latest/VsatStar.apk>
   - скачается `VsatStar.apk` (последняя сборка).
2. Откройте скачанный файл и установите (разрешите установку из неизвестных источников).
3. Откройте приложение → шестерёнка → введите логин и пароль от панели.

Нужен Android 8.0 или новее.

## Сборка

```
cd android
./gradlew assembleRelease
```

APK: `app/build/outputs/apk/release/app-release.apk`. Тесты: `./gradlew testDebugUnitTest`.

## Файлы

| Файл | Назначение |
|---|---|
| `Panel.kt` | Запросы к панели: вход, переключение, logout, трафик (через Wi-Fi) |
| `UsageParser.kt` | Разбор страницы трафика (перенос `parse_usage` из Python) |
| `Vsat.kt` | Действия и текущее состояние, общее для экрана и шторки |
| `StatusService.kt` | Значок в шторке, автообновление трафика, автоотключение |
| `IdleWatcher.kt` | Логика "час без трафика" |
| `Notifier.kt` | Уведомления |
| `MainActivity.kt`, `SettingsActivity.kt` | Экраны |
